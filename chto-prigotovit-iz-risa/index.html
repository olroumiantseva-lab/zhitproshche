Что можно приготовить из риса кроме гарнира

Рис подходит для блюд с овощами, курицей, грибами, запеканок и домашних тефтелей. С морковью, луком и зелёным горошком получается яркое овощное блюдо, а с яйцом и овощами — сытный жареный рис. Для запеканки можно добавить сыр и другие продукты, которые есть дома.

Как выбрать блюдо из риса

Для рассыпчатого риса важно учитывать сорт крупы и количество воды. Если рис уже сварен, его можно использовать для запеканки или быстро обжарить с овощами; готовый рис храните в холодильнике и не оставляйте надолго при комнатной температуре.
